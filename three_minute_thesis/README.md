# 3MT Prep

This folder contains a 3 Minute Thesis single-slide package for B.A.I.L.I.F.F.

## Build the slide
Run from repo root:

```bash
python three_minute_thesis/build_3mt_slide.py
```

Output:
- `three_minute_thesis/output/BAILIFF_3MT_slide.pptx`

## Content files
- `three_minute_thesis/script_3mt.md` - draft 3-minute speaking script + timing
- `paper/plots/family_effect_snapshot.png` - chart used in the slide

## 3MT rule checklist (quick)
Source: UQ 3MT Competitor Guide  
https://threeminutethesis.uq.edu.au/resources/3mt-competitor-guide

- Use exactly one static slide.
- No slide transitions or animations.
- No audio/video embeds.
- No props or costumes.
- Talk is spoken live and capped at 3 minutes.
- Keep slide readable from a distance (large text, low clutter).
